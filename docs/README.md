# 文档索引

当前路线是两个真实进程：原版离线 OW 保留英雄、手部、动画与 HUD；Minecraft 负责实际世界、运动、碰撞和存档。先读当前接手记录，再查专题；旧 PID、旧截图和离线 fixture 都不能代替本机验收。

这是经白名单复制与路径脱敏的公开源码快照。`research/`、`data/`、`dist/`、根目录机器配置、存档与归档文档没有公开；专题内提到的本机证据文件可能不随快照提供。历史状态按记录日期阅读。
