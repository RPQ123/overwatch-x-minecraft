## 解压和开始

1. 将 `OWMC-1.0.0.zip` 完整解压，得到一个 `OWMC-1.0.0` 文件夹。完整包 ZIP 超过 4 GB，请存放在 NTFS 或 exFAT 磁盘；FAT32 的单文件大小限制会阻止复制。不要在压缩包预览窗口中直接启动。
2. 打开该文件夹，双击 **`ow x mc 启动器.exe`**。
3. 默认停在启动器主页，点击 **“开始游戏”** 进入全屏加载。手动开启“打开即启动”后，下次打开会自动开始。两个游戏在遮罩后启动，期间暂时静音并锁定游戏输入。合成画面连通后，遮罩淡出并切到原版英雄选人。Windows 要求手动确认焦点时，按画面提示点击 **“进入游戏”**。加载失败时可按提示查看日志、重试或退出。
4. 选择英雄后，点击原版游戏窗口游玩。退出时回到启动器，使用 **“结束游戏”**，等待正常保存和恢复完成。

完整一键包预期离线启动，Python、Java、客户端、库和模组均随包携带，不需要玩家安装开发工具。若出现“首次运行／下载 MC”页，表示该副本仍有文件缺失或出厂校验尚未完成，请保留提示并联系制作者。**当前压缩产物是本地测试快照，不能把静态检查通过当作新电脑一键可玩的证明。**

中文和空格目录受支持；建议放在自己可读写、路径较短的位置，例如 `D:\游戏\OWMC-1.0.0`。启动器需要在包内保存设置、日志和世界，不宜放进需要提升权限才能写入的位置。移动或改名时先正常结束游戏，再移动整个文件夹。

## 电脑要求

- 64 位 Windows 10 2004 或更新版本，或 64 位 Windows 11；不支持 32 位系统。包内保留的少数 x86 错误报告辅助程序不改变主程序的 x64 要求。
- 显卡和驱动须能运行 Direct3D 11 与 Minecraft 1.21.1 所需的 OpenGL。仅有系统 DLL 不代表显卡功能已通过测试。
- 建议 16 GB 内存；准备检查至少要求 8 GB。建议解压前留出 20 GB 以上可用空间，便于同时保留 ZIP、解压文件和后续世界。
- 日常启动使用普通用户权限，启动器、OW、Minecraft 应由同一用户、同一权限级别启动。无需把游戏设为“始终以管理员身份运行”。修改杀毒软件设置或安装系统运行库可能另需管理员确认。

当前静态审计发现：OW 的 `inject.dll` 需要 VC++ 2015 系列的 `msvcp140.dll`、`vcruntime140.dll`、`vcruntime140_1.dll`；现有副本的这些文件位于 Java/Python 子目录，OW 目录未配齐。新电脑可能缺少系统安装版本，制作者需补齐并验证 app-local 布局。若启动提示这些文件缺失，请向制作者索取修复包，不要从零散 DLL 网站下载。Windows 10/11 自带 UCRT；Microsoft 的 [UCRT 部署说明](https://learn.microsoft.com/en-us/cpp/windows/universal-crt-deployment?view=msvc-170) 和 [VC++ DLL 部署说明](https://learn.microsoft.com/en-us/cpp/windows/determining-which-dlls-to-redistribute?view=msvc-170) 区分了两者。

## 按键

先确保原版游戏窗口处于前台。笔记本可能需要同时按 `Fn` 才能发送 F6–F11。

| 按键 | 功能 |
| --- | --- |
| WASD / 鼠标 | 移动 / 转向 |
| 空格 | 跳跃；开启飞行时上升 |
| Ctrl | 飞行时下降 |
| 鼠标左键 / 右键 | 当前英雄的主攻击 / 次攻击（若有） |
| R / V | 装弹 / 近战（取决于英雄） |
| Shift / E | 当前英雄技能，名称、阶段和冷却查看原版 HUD |
| Q | 终极技能，需要充能且满足当前英雄的原版施放条件 |
| H | 返回原版选人界面；按界面提示选择英雄 |
| F5 | 当前源码新增英雄召唤 / 生存模式菜单；现存旧 1.0.0 包未同步，需新版包 |
| F6 | 切换项目飞行开关；按键可在启动器设置中调整 |
| F7 | 世界设置：白天、黑夜、黄昏、固定白天、夜视等 |
| F8 | 传送门菜单；按当前已装模组列出可用入口 |
| F9 | 召唤菜单，包含随机怪物、目标批次、单体列表和清理 |
| F10 | Boss 入口菜单；可用项目取决于当前档案实际安装的模组 |
| F11 | 实验辅助补给：大招充能和已接入的技能冷却恢复；施法期间或条件不符时会拒绝 |

F7–F10 菜单用主键盘数字或小键盘数字选择；分页菜单通常 `1–8` 选项目、`9` 下一页、`0` 上一页，再按对应功能键关闭，以屏幕提示为准。F7 当前是世界设置，F9 当前是召唤，F10 当前是 Boss；早期说明中的快捷传送门和 F12 Boss 映射已经更换。

F5 是宣传片之后的源码更新：根菜单 `1` 选单个英雄、`2` 召唤全部 12 位训练 NPC、`3` 清理本人召唤、`4` 切换生存 / 无敌模式。2026-11-03 静态核对时，当前开发 JAR 已有该实现，现存 `dist/OWMC-1.0.0` JAR 未包含对应类；旧包不能用于验证新功能。发布前须同步整包并重新验收。训练 NPC 属于 MC 实体，不等同于完整原版英雄 AI。

菜单、召唤与补给功能受存活、创造模式、世界状态等条件限制。没有安装某个模组时，不能靠选择菜单条目获得它的世界或 Boss。英雄使用旧离线版本的技能设计，不能按现行正式服名称推断行为。部分英雄、Boss 全程战斗和技能仍待逐项实测；F11 也不保证恢复所有燃料或多充能资源。

## 常见问题

**一直停在启动中、只有一个游戏窗口，或看到黑屏。** 保留启动器中文错误。远程桌面、驱动切换分辨率和显示模式被系统拒绝会影响原版初始化；先用启动器正常结束，再在本地解锁的桌面重试。分辨率兼容性仍待干净系统实测，不要把后台进程存在当成加载成功。

**出现首次准备页、要求下载或选择文件。** 完整出厂包预期直接进入主页。检查是否完整解压、是否有文件被隔离、ZIP 校验是否一致。保留原目录；不要反复覆盖个人存档，也不要手改 JSON 把“已安装”强行设为 true。

**移动目录后不能启动。** 移动整个文件夹，确认 `runtime`、`game`、`minecraft-1.21.1` 等子目录仍在。若路径过长报错，移到盘符下较短的位置；不要逐个复制 EXE 或单独改配置中的开发机路径。

**F8/F10 缺少某个模组入口，或 F9 没有生成目标。** 菜单以实际安装和当前条件为准。查看屏幕提示；不把缺模组的旧世界强行载入另一套档案。保留日志交给制作者。

**退出、备份和卸载。** 使用启动器的“结束游戏”，等两套进程正常退出并保存。世界通常位于 `guest-passthrough-client/saves/`，自行选择的档案目录则以设置为准。备份整个世界及其配置。卸载前先移走自己的存档和日志，再自行移除整包。

## Defender / 杀毒软件拦截

本项目会向自己启动的离线 OW 进程加载合成与输入适配 DLL，使用进程内存、回调和本地共享内存。`GameClientApp.patched.exe`、游戏自带的 `inject.dll`、`native-host/build/owmc-*.dll` 和未签名启动器可能因此被 Defender、360、火绒等安全软件拦截；这是潜在拦截点，不是本轮检测到恶意软件或确认误报的结论。

先检查压缩包来源、SHA256 和安全软件的具体检测记录。确认自己信任该副本后，可在保护历史／隔离区按具体记录恢复对应文件。确有需要时，在 Windows 安全中心的“病毒和威胁防护 → 管理设置 → 排除项 → 添加或删除排除项”中，仅选择本包目录；排除会减少该目录的扫描保护。第三方杀毒软件在自己的隔离区／信任区处理同一精确路径。无需关闭整机防护或排除整个磁盘。[Microsoft 官方说明](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/virus-and-threat-protection-in-the-windows-security-app)

未签名文件的 SmartScreen 提示、应用控制策略、受控文件夹访问与病毒隔离可能是不同问题。若是组织设备的策略阻止，保留错误并交给管理员，不要反复提升游戏权限。

## 校验和反馈

压缩包旁的 `OWMC-1.0.0.zip.sha256` 给出整包 SHA256。可在 ZIP 所在目录用 PowerShell 计算：

```powershell
Get-FileHash -LiteralPath '.\OWMC-1.0.0.zip' -Algorithm SHA256
```

比较得到的十六进制值与 `.sha256` 第一段是否一致。压缩包旁的 `OWMC-1.0.0.zip.manifest.json` 另列压缩快照里逐文件的大小和 SHA256；它留在包外，解压内容保持与源目录一致。

反馈时记录系统版本、显卡/驱动、显示分辨率、解压路径、启动器中文错误和出问题的按键。启动器日志位于 `research/launcher/`，Minecraft 日志通常是 `guest-passthrough-client/logs/latest.log`。不要发送账号凭据或整份个人存档；先保留原始错误，便于制作者复现。
