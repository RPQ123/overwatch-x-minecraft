完整解压后，双击根目录 **`ow x mc 启动器.exe`**，在主页点击 **“开始游戏”**。可在启动器里开启“打开即启动”，下次打开时自动开始。全屏加载时暂时静音并锁定游戏输入，合成就绪后切到原版选人。退出请使用启动器的 **“结束游戏”**，等待正常保存。完整包 ZIP 超过 4 GB，请使用 NTFS 或 exFAT 磁盘，FAT32 无法存放。

完整一键包预期自带运行时、游戏依赖和模组，离线使用；出现首次准备／下载页表示该副本仍有缺项或校验未完成，请保留提示交给制作者。当前为本地测试快照，换机实际启动、显示兼容和完整可玩性仍待验收。

按键：`WASD` 移动，鼠标左右键攻击，`Shift/E` 技能，`Q` 大招，`R` 装弹，`V` 近战，`H` 选人。`F6` 飞行，`F7` 世界设置，`F8` 传送门，`F9` 召唤，`F10` Boss，`F11` 实验补给；菜单用数字键选择，以实际已装模组和界面提示为准。

详细的解压、电脑要求、技能、杀毒软件拦截、备份和常见问题，请阅读 **[玩家说明](docs/PLAYER-README.md)**。构建与组件范围见 [MODPACK](docs/MODPACK.md)，第三方许可保留在包内。

普通用户权限启动即可。缺少 `msvcp140.dll` 等运行库文件时向制作者索取修复包。安全软件提示应先核对来源、校验值和检测记录，再按玩家说明处理具体文件。
